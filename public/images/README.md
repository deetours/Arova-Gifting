# Arova image drop folder

Add approved website images to the subfolders below. See `../../IMAGE_ASSET_CHECKLIST.md` for exact filenames, recommended dimensions, crops, and the full delivery checklist.

- `brand/` — wordmark and icon
- `home/` — homepage hero and social preview
- `collections/` — four collection photographs
- `concepts/` — Build-a-kit choice card images
- `products/` — confirmed product galleries

Preferred photo format: WebP. Keep filenames lowercase and hyphenated as listed in the checklist.
